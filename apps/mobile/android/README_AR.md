# تطبيق Fuchsia Boutique الأصلي — Android

تطبيق Android أصلي بلغة **Kotlin** وواجهة **Jetpack Compose** وتنقّل **Navigation Compose (`NavController` و`NavHost`)**. ترتبط الواجهات بخادم API الفعلي؛ لا تُستخدم بيانات تجريبية لمسارات الحساب أو التجارة. استثناء التحقق الوحيد هو عرض رمز OTP على الشاشة حين يطلبه العميل صراحةً في بيئة التطبيق.

للتسليم لمبرمج أو إعداد بيئة العمل والبناء والتوقيع والاختبار، راجع [دليل المطور الشامل](../DEVELOPER_GUIDE_AR.md). شيفرة APK الحالية مدمجة في هذا المستودع داخل `apps/mobile/android/`؛ أما `apps/mobile/app/` فهي نسخة Expo مرجعية.

## الواجهات والميزات

- صفحتا ترحيب متجاوبتان بشعار فوشيا الأصلي: تظهران مرة واحدة بعد التثبيت الجديد، ثم يبدأ التطبيق من الرئيسية عند الفتح التالي. تُتخطّيان عند ترقية تثبيت سابق، ولا تعودان بعد الإغلاق أو تسجيل الخروج.
- انتقالات أصلية سلسة بين الوجهات، مع ظهور شعار فوشيا لفترة قصيرة أثناء الانتقال، ودعم الرجوع بنظام Android.
- شريط تنقّل سفلي واضح للرئيسية وطلباتي وحسابي والإعدادات.
- تسجيل الدخول وإنشاء الحساب والتحقق الفعلي من OTP، إلى جانب جلسة زائر حقيقية ينشئها الخادم عند اختيارها.
- تخزين رمز الجلسة بتشفير AES-GCM عبر مفتاح Android Keystore، وإرسال Bearer token إلى واجهات الملف الشخصي والعناوين والحجوزات والطلبات المحمية.
- الصفحة الرئيسية والتصنيفات والمنتجات والسلة متصلة بـAPI.
- دليل عناوين دائم مرتبط بالحساب: إضافة عدة عناوين وتعديلها وحذفها وتعيين العنوان الافتراضي واختياره مباشرةً في Checkout.
- إتمام الطلب متصل بـ`/api/orders`، مع الدفع عند التوصيل أو الدفع الجزئي/الكامل، ورفع إيصال التحويل إلى الخادم.
- اختيار موقع التوصيل من خريطة حقيقية (MapLibre + OpenFreeMap)، أو عبر GPS بإذن أثناء الاستخدام؛ تُرسل الإحداثيات مع الطلب.
- طلب الهدية يمرر بيانات المستلم ورسالة الإهداء وإخفاء السعر ضمن الطلب.
- شاشة «طلباتي» لتاريخ الطلبات وتتبع الحالة بتحديثات API دورية.
- حجز الطاولات عبر `/api/reservations` بجلسة Bearer موثقة، مع اختيار الفرع والموعد وعدد الأشخاص.
- إعدادات المظهر المحفوظة (نهاري/ليلي/حسب الجهاز) وقفل التطبيق بمصادقة Android الحيوية بعد تحقق الجهاز، وإدارة الحساب والعناوين.
- صفحات سياسة الخصوصية وشروط الاستخدام وكيفية استخدام التطبيق، والتواصل عبر اتصال الهاتف أو WhatsApp، ومشاركة التطبيق، ومعلومات الإصدار.
- تمت صياغة الواجهات العربية بصياغة محايدة وشاملة.

## واجهات API ومخطط البيانات

- `GET/PATCH /api/auth/profile`: قراءة وتعديل بيانات الحساب، ويُستخدم المستخدم الموثق من Bearer token بدل الاعتماد على `userId` من العميل.
- `GET/POST /api/addresses` و`PATCH/DELETE /api/addresses/:id`: دفتر العناوين المحمي، مع عزل كل عنوان بصاحبه وتعيين عنوان افتراضي. يضيف ترحيل قاعدة البيانات جدول `user_addresses` بطريقة آمنة وقابلة لإعادة التشغيل.
- `/api/reservations` وسجل أحداث الطلبات: تتطلب الجلسات الموثقة للحساب، مع ترحيلات تضيف الجداول المفقودة ولا تحذف بيانات قائمة.
- نشر ملفات المصدر لا يحدّث بيئة الإنتاج تلقائيًا. قبل اعتماد الميزات الجديدة على النطاق المنشور، يجب نشر إصدار API الحالي على **مشروع الاستضافة القائم** والتحقق من نجاح ترحيلات قاعدة البيانات في البيئة المقصودة؛ لا تشغّل الترحيلات على قاعدة إنتاج دون التأكد من إعداد `DATABASE_URL` وإجراءات النسخ الاحتياطي.
- استثناء OTP المرئي الوحيد: يرسل العميل رأس `X-Fuchsia-OTP-Debug` عندما يكون خيار إظهار الرمز مفعّلًا.

## البناء

المطلوب: JDK 17 أو أحدث، وAndroid SDK مع المنصة 37 وأدوات البناء 36.0.0.

```bash
cd apps/mobile/android
printf 'sdk.dir=%s\n' "$HOME/android-sdk" > local.properties
./gradlew :app:assembleDebug
```

لإنشاء APK Release موقّع:

```bash
cd apps/mobile
./scripts/build-release-apk.sh
```

يحافظ التطبيق على `applicationId = com.fuchsia.platform` ومفتاح Release الدائم للمتجر كي يُثبّت كتحديث. الإصدار الحالي في المصدر: `versionCode = 5` و`versionName = 1.3.0`. تُحفظ مادة المفتاح وكلمات مروره خارج Git؛ لا تضعها في المستودع.

### الخرائط والموقع

تستخدم شاشة الإتمام MapLibre Android وخريطة OpenFreeMap بأسلوب `positron` من دون مفتاح API. يمكن تحريك الخريطة وتكبيرها ووضع دبوس التسليم واعتماد الإحداثيات، أو طلب الموقع الحالي عبر GPS بعد منح الإذن أثناء الاستخدام. يتطلب تحميل الخرائط اتصالًا بالإنترنت. يظهر الإسناد المطلوب إلى OpenFreeMap وOpenMapTiles وOpenStreetMap داخل الواجهة. الخدمة العامة بلا SLA؛ يمكن لاحقًا استخدام مزوّد أو استضافة مُدارة إذا تطلب التشغيل ضمان توافر تعاقديًا.
