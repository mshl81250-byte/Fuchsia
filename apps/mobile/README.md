# تطبيق Fuchsia Android

تطبيق عميل Android مبني بـ **React Native + Expo Router + TypeScript**، ويعيد استخدام خادم Fuchsia الحالي دون وضع أسرار قاعدة البيانات أو الإدارة داخل التطبيق.

## التشغيل

من جذر المستودع:

```bash
pnpm install
pnpm --dir apps/mobile start
```

ثم افتح المشروع في Expo Go أو شغّل:

```bash
pnpm --dir apps/mobile android
```

اضبط عنوان الخادم عبر `apps/mobile/.env` اعتمادًا على `.env.example` عند الحاجة. القيمة الافتراضية هي خادم المعاينة المنشور.

## الوظائف الحالية

- شاشة افتتاحية RTL بهوية فوشيا البصرية.
- دخول العميل أو الدخول كزائر عبر `/api/auth/login` و`/api/auth/guest`.
- تخزين جلسة المستخدم في `expo-secure-store`.
- الرئيسية والمنتجات المميزة.
- متجر المنتجات والبحث والإضافة للسلة.
- تفاصيل المنتج وتعديل الكمية.
- السلة وحساب الإجمالي ورسوم التوصيل.
- إتمام الطلب مع الاسم والهاتف والعنوان وتحديد GPS ضمن نطاق صنعاء.
- الدفع عند التوصيل أو الدفع الكامل/العربون عبر المحافظ، وإرفاق إيصال من الجهاز.
- قائمة الطلبات وتفاصيل الطلب وبيانات الموصّل.
- الملف الشخصي وتعديل بيانات العميل وتسجيل الخروج.

## التحقق والبناء

```bash
pnpm --filter @workspace/mobile run typecheck
pnpm --filter @workspace/mobile exec expo export --platform android
```

مخرجات `expo export` مؤقتة ولا تُرفع إلى Git. بناء APK/AAB الإنتاجي يتم لاحقًا عبر EAS بعد ضبط حساب Expo وملف credentials.
