# إعداد تخزين صور القاعات والتأجير

يرفع التطبيق صور القاعات والكوش والطاولات عبر `POST /api/uploads/image`، ثم يخزن رابط الصورة في بيانات القاعة أو المنتج. يعتمد الخادم على واجهة S3، لذلك لا يرتبط منطق التطبيق بمزود صور بعينه، ولا تُحفظ بيانات الاعتماد داخل تطبيق Android أو GitHub.

## إعداد الخادم

أضف المتغيرات التالية إلى **مخزن أسرار بيئة تشغيل API** (وليس إلى ملف `.env` مرفوع للمستودع):

- `OBJECT_STORAGE_ENDPOINT`: عنوان S3 API الخاص بالمزود. اتركه فارغًا عند استخدام AWS S3 مباشرة.
- `OBJECT_STORAGE_REGION`: منطقة المزود؛ مثل `auto` لدى Cloudflare R2، أو قيمة المنطقة التي يعرضها مزودك.
- `OBJECT_STORAGE_BUCKET`: اسم الحاوية/الدلو.
- `OBJECT_STORAGE_ACCESS_KEY_ID` و`OBJECT_STORAGE_SECRET_ACCESS_KEY`: مفتاحا الخادم، ولا ترسلهما داخل المحادثة أو تطبيق الهاتف.
- `OBJECT_STORAGE_PUBLIC_BASE_URL`: عنوان HTTPS عام للقراءة، ويفضل نطاق CDN مخصص. يجب أن يستطيع العميل فتح رابط الصورة من الإنترنت.

ينشئ الخادم أسماء ملفات عشوائية ضمن بادئات منفصلة للقاعات ومنتجات التأجير، ويقبل JPG وPNG وWebP حتى 7 ميغابايت. يجب إعداد سياسة المزود أو CDN لقراءة كائنات الصور العامة، مع إبقاء صلاحية الكتابة للمفتاح الذي يستخدمه الخادم فقط.

## اختيار المزود

واجهة S3 المتوافقة تسمح بتغيير المزود عبر إعدادات البيئة دون إعادة كتابة تدفق التطبيق. من الخيارات الممكنة Cloudflare R2 أو Backblaze B2 أو AWS S3 أو خدمة محلية/خاصة متوافقة مع S3. **هذا لا يعني ضمان توفر التسجيل أو لوحة التحكم أو الدفع في بلد بعينه**؛ اختبر إنشاء الحساب والوصول إلى لوحة المزود وendpoint من بيئة الخادم قبل وضع أسرار الإنتاج.

## مراجع رسمية

- [Cloudflare R2 S3 API](https://developers.cloudflare.com/r2/api/s3/api/): يوضح endpoint وواجهة S3 المدعومة؛ تستخدم R2 قيمة المنطقة `auto`.
- [Cloudflare R2 data location](https://developers.cloudflare.com/r2/reference/data-location/): تفاصيل التلميحات الجغرافية والقيود القضائية لموقع البيانات.
- [Backblaze B2 S3-Compatible API](https://www.backblaze.com/docs/cloud-storage-s3-compatible-api): يشرح التوافق مع صياغة S3 وروابط الرفع/التنزيل الموقعة مسبقًا.
- [Amazon S3 API reference](https://docs.aws.amazon.com/AmazonS3/latest/API/Welcome.html): مرجع واجهة S3 الرسمية.
