# بيانات معاينة القاعات والإيجار

يوفر `artifacts/api-server/src/seed-demo.ts` بيانات واضحة الوسم بـ **[معاينة]** لتجربة واجهات القاعات والكوش والطاولات:

- خمس قاعات: نسائية، رجالية، وقاعات تتيح القسمين.
- ستة عناصر تأجير: كوش للنساء والرجال، وطاولات بأحجام وألوان ومخزون مختلف.
- أربع حجوزات تقويم تجريبية لتوضيح الأيام المشغولة.

السكربت **إضافي وتكراري**: يضيف أو يحدّث سجلات المعاينة التي أنشأها فقط، ولا يفرّغ الجداول ولا يحذف سجلات العملاء أو الأعمال. لا يُشغّل تلقائيًا مع بدء الخادم.

## التشغيل في قاعدة staging أو التطوير فقط

تأكد أولًا أن `DATABASE_URL` يتصل بقاعدة منفصلة عن الإنتاج، وأن اسم قاعدة البيانات يتضمن `staging` أو `demo` أو `dev` أو `test`. بعد تثبيت الاعتماديات:

```bash
DATABASE_URL='mysql://USER:PASSWORD@HOST/fuchsia_staging' \
FUCHSIA_DATABASE_ENV=staging \
FUCHSIA_DATABASE_NAME=fuchsia_staging \
FUCHSIA_DEMO_SEED_CONFIRM=SEED_DEMO_ONLY \
pnpm --filter @workspace/api-server run seed:demo
```

يُرفض التشغيل ما لم تتطابق قاعدة البيانات الفعلية مع الاسم المعلن، ويكون نوع البيئة غير إنتاجي، ويُعطى تأكيد المعاينة صراحة. لا تُدرج بيانات دخول حقيقية في ملفات المستودع.

## تنبيه تشغيلي

هذه السجلات مخصصة لبيئة المعاينة فقط. لا تُعرض على العملاء في بيئة الإنتاج ولا تستخدم للتحقق من قاعة أو صاحب متجر حقيقي. بيانات الإنتاج يجب أن يدخلها أصحاب القاعات والتأجير المعتمدون عبر حساباتهم.
