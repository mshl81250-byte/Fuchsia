# نظام التصميم المشترك — Fuchsia Boutique

## الهدف

توحد وحدة Android المشتركة `apps/design-system/android` المظهر الأساسي لتطبيق العميل وتطبيق الشريك: لوحة الألوان، الوضعان الفاتح والداكن، خط Cairo العربي، اتجاه RTL، ومكونات Compose المعاد استخدامها. أي ضبط لاحق للألوان أو الخطوط يُجرى في هذه الوحدة بدل اختلاف التطبيقين.

## الخط والطباعة

- الخط العربي الموحد: **Cairo**، بوزن عادي وشبه عريض وعريض.
- `Typography` يغطي كل الأنماط من `displayLarge` إلى `labelSmall`، مع ارتفاع سطر مناسب للنص العربي.
- اتجاه التخطيط RTL يضبطه `FuchsiaTheme` مركزيًا.
- لا تستخدم أحجامًا أو ألوانًا ثابتة للنصوص الجديدة إذا كان نمط `MaterialTheme.typography` و`colorScheme` يحقق الغرض.

## المكونات المشتركة المتاحة

من الحزمة `com.fuchsia.designsystem`:

- `FuchsiaTheme`: يطبق الألوان والطباعة وRTL، ويتبع إعداد التطبيق أو نظام الجهاز.
- `FuchsiaColors`: رموز لونية متكيفة، منها `Primary`, `Ink`, `Muted`, `Rose`, `Gold`, `Success`, `Warning`, `Error`.
- `FuchsiaPrimaryButton`: زر أساسي موحد، مع تعطيل تلقائي أثناء التحميل وحالة انتظار مرئية.
- `FuchsiaSurfaceCard`: بطاقة ذات زوايا وحدود موحدة.
- `FuchsiaSectionTitle`: عنوان قسم مع نص تفصيلي اختياري.
- `FuchsiaStatusChip` و`FuchsiaStatusTone`: شارات الحالات المحايدة والناجحة والتحذيرية والخطأ والمعلومات.

مثال:

```kotlin
FuchsiaTheme {
    FuchsiaSurfaceCard {
        Column {
            FuchsiaSectionTitle(title = "حجوزاتي", detail = "3 طلبات")
            FuchsiaPrimaryButton(text = "متابعة", onClick = onContinue)
        }
    }
}
```

## الدمج الحالي

- تطبيق العميل وتطبيق الشريك مرتبطان بوحدة Gradle المشتركة نفسها.
- ثيم العميل الحالي يبقى واجهة توافقية كي لا تتطلب هذه الخطوة تعديل كل شاشة على حدة؛ الرموز التي تستعملها الشاشات تقرأ الآن من لوحة الوحدة المشتركة.
- تطبيق الشريك يستخدم `FuchsiaTheme` مباشرةً ويتبع الوضع الليلي للنظام. تم تحويل شاشة تسجيل الدخول إلى البطاقة والزر المشتركين.
- زر Commerce وعناوين الأقسام في العميل تستخدم المكونات المشتركة، وشارات حالة حجوزات الشريك تستخدم `FuchsiaStatusChip`.
- المكونات الحالية جاهزة لتوسيع إعادة الاستخدام في بقية الشاشات في الخطوات التالية.

## إرشادات الإتاحة

- حافظ على النص الأساسي أبيض في الوضع الداكن، ولا تستخدم درجات رمادية منخفضة التباين للنصوص الضرورية.
- استعمل الألوان الدلالية للحالة مع النص/الأيقونة، ولا تعتمد على اللون وحده لتوصيل معنى الحالة.
- حافظ على مساحة لمس مناسبة للأزرار والحقول، واتبع قياسات المكونات المشتركة قبل إنشاء بدائل محلية.
- استخدم اللمسات الذهبية باعتدال؛ الصور والمساحات والتنظيم هي مصدر الإحساس بالفخامة.
